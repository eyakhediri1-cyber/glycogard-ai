🩺 GlycoGuard — AI Diabetes Management Platform

GlycoGuard is a full-stack HealthTech application that helps type 2 diabetes patients track their health and receive AI-powered personalized insights to improve daily decision-making and early risk detection.

Key Features:
  Health Tracking: blood sugar, nutrition, mental health, medications
  AI Companion: personalized health guidance (OpenAI-powered)
  Risk Scoring Engine: real-time health risk assessment (0–100)
  Analytics Dashboard: trends, statistics, and health insights
  Secure System: JWT authentication + protected APIs
  Tech Stack


Frontend: React, Chart.js, Axios
Backend: Node.js, Express.js
Database: PostgreSQL
AI: OpenAI API
DevOps: Docker, Docker Compose


Architecture:
  RESTful API (modular Express backend)
  React component-based UI
  PostgreSQL relational schema
  JWT-based stateless authentication
  Dockerized full-stack setup

  
Quick Start:
  git clone <repo>
  cd GlycoGuard
  export OPENAI_API_KEY="your-key"
  docker-compose up -d


App:
Frontend: http://localhost:3000
